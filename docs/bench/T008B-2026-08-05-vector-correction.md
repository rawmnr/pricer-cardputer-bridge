## Correction evidence

The retained T006B vectors had two application-framing defects and one parameter
field defect:

1. The internal PLID bytes `3F B7 B3 02` were transmitted instead of the wire
   order `02 B3 B7 3F`.
2. Graphic commands `0x05`, `0x20`, and `0x01` omitted the MCU envelope
   `34 00 00 00`.
3. The 8 × 8 parameter body encoded compression `1` and page `0` instead of
   raw compression `0` and page `1`.

The corrected vectors are generated by `scripts/generate_vectors.py` from the
host builders and retained under `tests/vectors/`. Tests compare the generated
frames against independent explicit hex, verify CRC metadata, verify the binary
files, and verify the embedded firmware arrays.

| Vector | Command | Correct length | CRC16 little-endian |
|---|---:|---:|---|
| `wake.bin` | `0x17` raw | 38 bytes | `f1c3` |
| `params-8x8-color.bin` | `0x05` MCU | 38 bytes | `c847` |
| `data-8x8-color.bin` | `0x20` MCU | 34 bytes | `9c4d` |
| `refresh.bin` | `0x01` MCU | 38 bytes | `8c01` |
